## 你的筆記本：Google Colab

**筆記本**（notebook）是一種把文字和程式碼放在一起的文件。你讀一段文字，接著執行它下面的程式碼，結果就直接出現在那裡：一個數字、一張表或一張圖。從第 01 章起，每一章都有一本。

**Google Colab** 在 Google 的電腦上、透過你的網頁瀏覽器執行筆記本。你什麼都不用安裝，只需要一個免費的 Google 帳號和網路連線。

**一步一步開啟你的第一本筆記本。** 畫面會隨時間改版，所以這些步驟描述的是「要找什麼」，而不是「點哪裡」。

1. 前往[第 01 章](notebooks/01_python_with_ai.ipynb)的筆記本頁面。靠近頁面標題的地方有一個 **Open in Colab** 連結，點下去。Colab 會在新分頁開啟，並擁有這本筆記本自己的一份副本。
2. 如果 Colab 要你登入，請用你的 Google 帳號。
3. Colab 可能警告這本筆記本不是 Google 寫的。對任何 Google 以外的筆記本來說，這都很正常；這一本來自本書公開的程式碼儲存庫。選擇仍要執行。
4. 找到第一個**程式碼儲存格（code cell）**，標題是 *Google Colab setup*。執行它：按下它左邊的圓形播放鍵，或點一下儲存格內部再按 **Shift + Enter**。它會下載本書的資料和工具，請等一分鐘。
5. 接著由上往下，一個一個執行後面的儲存格。每個儲存格跑完後，結果會顯示在它下面。
6. **儲存你自己的副本。** 在 Colab 的 File（檔案）選單中，選擇把副本儲存到你的 Google 雲端硬碟。不這麼做的話，關掉分頁後你的修改就會消失。
7. 如果卡住了，用 Runtime（執行階段）選單**重新啟動**，再從最上面開始跑。順序很重要：一個儲存格只能使用前面儲存格建立出來的東西。

如果沒看到 Colab 連結，就自己開啟 Colab，選擇從 **GitHub** 開啟筆記本，輸入 `ancientsky/python4epi`，然後在資料夾 `book_ph/zh/chapters/notebooks/` 裡挑一本筆記本。

## AI 助理是什麼，又不是什麼

AI 寫程式助理是一個讀過海量文字與程式碼的程式。你輸入需求時，它一次一個字地**預測**一個有幫助的回答長什麼樣子。這就是它為什麼那麼快，也是它為什麼可能出錯。

| AI 助理**是** | AI 助理**不是** |
|---|---|
| 快速的程式碼初稿寫手 | 永遠正確的計算機 |
| 很會解釋你看不懂的那一行 | 知道你的資料（除非你給它看） |
| 有耐心：同一件事問五次也行 | 對結果負責。**負責的人是你。** |

危險的不是明顯的錯誤，而是那種執行時沒有任何錯誤訊息、看起來很專業、卻給出**錯誤數字**的程式碼。助理可能很有自信地出錯：錯的分母、不存在的函式、日期的月日讀反了。報告是用你的名字發出去的，不是助理的名字。

在這本書裡，助理叫做 **Tala**。請使用你的單位允許的任何助理；方法都一樣。

## 方法：提問 → 執行 → 檢查

```{figure} images/ask_run_check_zh.svg
:alt: 三站組成的循環。提問：說清楚欄位名稱，只給假的範例資料。執行：在 Colab 執行並讀懂錯誤訊息。檢查：用能手算的小例子驗證。從檢查回到提問的箭頭標示「修正後再問一次」。
:width: 100%
本書中的每一段程式碼，至少都會繞這個循環一圈。
```

1. **提問。** 說明你要什麼，附上欄位名稱和幾列虛構資料。
2. **執行。** 把程式碼貼進儲存格執行。如果出現錯誤，先讀最後一行，它通常會告訴你哪裡有問題。
3. **檢查。** 用一個小到能手算的案例測試程式碼。總數和列數對得上嗎？分母對嗎？只要有任何不對勁，就把你看到的告訴 Tala，再問一次。

**檢查**是大家最常跳過的一步，也是本書最著重訓練的一步。

## 好好提問：好提示詞的五個要素

**提示詞**（prompt）就是你輸入給助理的內容。好的提示詞換來好的程式碼。請放進：

1. **背景：** 資料是什麼、你想做什麼。
2. **欄位：** 精確的欄位名稱，拼法和檔案裡一模一樣。
3. **一個虛構的小例子：** 兩三列編出來的資料，絕不用真實資料。
4. **預期輸出：** 答案應該長什麼樣子。
5. **限制條件：** 你的需求：適合初學者、每一行都加註解、只用 pandas、附上檢查結果的方法。

**改進前：**（其中的 barangay（描籠涯，菲律賓最基層的行政區，類似台灣的村里）指的是病例所在的地區）

> count dengue per barangay

Tala 得猜一切：是哪個檔案、欄位叫什麼、你要的是表格還是圖。你會拿到*某種*程式碼，欄位名稱八成是錯的。

**改進後：**

:::{admonition} 問問 Tala
:class: ph-ask-tala
我是正在學 Python 的監測人員。我有一個 pandas DataFrame `df`，每一列是一位病例，欄位有 `case_id`、`disease`（`dengue` 或 `leptospirosis`）、`barangay` 和 `date_onset`。三列虛構資料：
`X-1, dengue, Barangay A, 2026-08-03` · `X-2, leptospirosis, Barangay A, 2026-07-27` ·
`X-3, dengue, Barangay B, 2026-08-04`。
請寫適合初學者的程式碼，計算每個 barangay 的**登革熱**病例數，由多到少排序，每一行都加上註解。以我這三列來說，預期結果是 A = 1、B = 1。另外也請告訴我怎麼檢查各項數字加起來是否正確。
:::

:::{admonition} Tala 說
:class: ph-tala-says
```python
dengue = df[df["disease"] == "dengue"]          # keep only dengue rows
counts = dengue["barangay"].value_counts()      # count rows per barangay
print(counts)
assert counts.sum() == len(dengue)              # check: every dengue row counted once
```
:::

:::{admonition} 檢查一下
:class: ph-check
1. 先用那三列虛構資料跑跑看。你說預期 A = 1、B = 1，結果是這樣嗎？
2. `assert` 那一行檢查總數。如果它沒有任何反應，代表數字加得起來。
3. 問問自己：它真的排除了鉤端螺旋體病那一列嗎？（有：Barangay A 顯示 1，不是 2。）
:::

注意好的提示詞裡**沒有**什麼：沒有姓名、沒有住址、沒有真實資料列。要得到好程式碼，你從來不需要真實資料。虛構的資料列就能發揮同樣的作用。

## 隱私承諾

在你往後的職涯中，你都會處理真實民眾的疾病資料。[第 02 章](02_privacy_first.md)會說明法律和技巧。在開始之前，先許下這個承諾。

:::{admonition} 隱私停看聽
:class: ph-privacy
**我的承諾。** 在把 AI 工具用在健康資料之前，我承諾：

1. 我**絕不**把姓名、電話、住址、證號、完整出生日期，或關於病患的自由文字備註**貼進** AI 聊天。
2. 我會**描述欄位**，並改用編造的範例資料列。
3. 我會把**原始檔案留在單位內**，只放在單位核准的電腦與硬碟上。
4. 每個數字離開我的桌面之前，我都會**檢查**，並記得負責的人是我，不是 AI。
5. 不確定時，我會**詢問我的資料保護長（Data Protection Officer）**。

每一列都是鄰居。
:::

## 小測驗

:::{div}
:class: ph-game ph-game-quiz
**小測驗：從這裡開始**

1. Tala 的程式碼執行時沒有任何錯誤。這告訴你什麼？
   - 答案是正確的 — 不對。程式碼可以跑得很順，卻給出錯誤的數字。
   - ✓ 只告訴你 Python 跑得動 — 你還是要用能手算的案例檢查結果。
   - Tala 測試過了 — Tala 看不到你的資料，也無法執行你的筆記本。
2. 下列哪一項可以放進提示詞？
   - 從 line list 取五列真實資料，這樣比較精確 — 絕對不行：真實資料列會識別出真實的人。
   - ✓ 精確的欄位名稱和兩列虛構資料 — 這樣就給了 Tala 所需的一切。
   - 病患的姓名，讓 Tala 了解這個病例 — 姓名絕不進 AI 聊天。
3. 在 Colab 裡，某個儲存格說某個變數沒有定義。最可能的原因是什麼？
   - ✓ 前面的某個儲存格還沒有執行 — 從最上面開始、依序執行。
   - Colab 壞了 — 重新啟動有時有用，但儲存格順序才是常見原因。
   - 你的電腦需要安裝 Python — 不用：Colab 在 Google 的電腦上跑 Python，你只需要瀏覽器。
:::

:::{admonition} Baon（帶走重點）
:class: ph-baon
- 筆記本把文字和程式碼放在一起；Colab 在你的瀏覽器裡執行它。從最上面開始執行儲存格，並在你的雲端硬碟存一份副本。
- 提問 → 執行 → 檢查：AI 助理預測的是「看起來合理」的程式碼，所以每個結果都要用能手算的案例檢查。對數字負責的人是你。
- 好的提示詞包含背景、精確的欄位、虛構的資料列、預期輸出和你的限制條件，而且不含任何真實的病患資料。
