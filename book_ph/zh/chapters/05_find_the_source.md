## 為什麼用病例對照研究？

在**世代研究（cohort study）**裡，你追蹤所有暴露或未暴露的人，並計算誰會生病。對 Santa Luz 來說，那表示要訪問好幾萬名居民，才找得到幾百個病例。在**病例對照研究（case-control study）**裡，你從生病的人（**病例**）出發，挑選條件相似但沒有生病的人（**對照**），然後比較兩組各自**暴露**的頻率。

Doc Mon 的團隊取了河岸八個 barangay 中 15 歲以上的 120 位可能或確診的鉤端螺旋體病病例。每個病例，他們從同一個 barangay 挑選兩位對照：240 位對照，共 360 人（`lepto_case_control.csv`）。

## 2×2 表

每個暴露都會變成一個 **2×2 表**：列是暴露與未暴露，欄是病例與對照。

|  | 病例 | 對照 |
|---|---|---|
| **暴露** | a | b |
| **未暴露** | c | d |

**勝算比（odds ratio, OR）**是 $\frac{a \times d}{b \times c}$。OR 等於 1 表示沒有關聯。大於 1 表示暴露在病例中較常見（危險因子）。小於 1 表示暴露在病例中較不常見（保護因子）。

:::{admonition} 問問 Tala
:class: ph-ask-tala
在 `cc` 裡，`waded_floodwater` 是 0/1，`status` 是 `case`/`control`。請做出 2×2 表，並計算涉水的勝算比。
:::

:::{admonition} Tala 說
:class: ph-tala-says
```python
t = pd.crosstab(cc["waded_floodwater"], cc["status"])
a, b = t.iloc[0, 0], t.iloc[0, 1]
c, d = t.iloc[1, 0], t.iloc[1, 1]
print(t)
print("Tala's OR =", round(a * d / (b * c), 2))
```
勝算比是 **0.18**。
:::

:::{admonition} Tala 搞錯了
:class: ph-oops
OR 0.18 的意思是涉水*保護*了人。Aling Nena 會笑出來。Maya 用兩種方式抓到這個錯誤：

1. **讀標籤。** `crosstab` 把列依 0 在 1 之前排序，所以第一列是「**沒有**涉水」。Tala 依位置讀儲存格，所以她的 *a* 其實是未暴露的病例。有一個軸被翻轉了，這會讓 OR 上下顛倒：0.18 = 1 ÷ 5.57。（把列*和*欄一起對調，並不會改變 OR，所以每個軸都要檢查。）
2. **先檢查方向是否合理。** **75%** 的病例涉過水，對照則是 **35%**。OR 必定遠大於 1。
:::

安全的做法是固定順序並替列和欄命名，讓任何人都讀得懂這張表：

```python
def two_by_two(data: pd.DataFrame, exposure: str) -> pd.DataFrame:
    """2x2 table: rows exposed / not exposed, columns cases / controls."""
    table = pd.crosstab(data[exposure], data["case"]).loc[[1, 0], [1, 0]]
    table.index = ["Exposed", "Not exposed"]
    table.columns = ["Cases", "Controls"]
    return table
```

對涉水來說，這給出 a = 90、b = 84、c = 30、d = 156，以及 **OR = 5.57**。

## 我們有多確定？95% 信賴區間

從 360 人得來的 OR 帶有抽樣誤差。**95% 信賴區間（confidence interval, CI）**給出與我們的資料相容的數值範圍。如果整個區間都在 1 之上（或之下），單靠機遇就不太可能解釋這個結果。簡單的 *Woolf* 方法在對數尺度上進行：

$$95\%\ CI = \exp\left(\ln OR \pm 1.96\sqrt{\tfrac1a+\tfrac1b+\tfrac1c+\tfrac1d}\right)$$

```python
se = math.sqrt(1 / a + 1 / b + 1 / c + 1 / d)
low, high = math.exp(math.log(or_wading) - 1.96 * se), math.exp(math.log(or_wading) + 1.96 * se)
```

:::{admonition} 檢查一下
:class: ph-check
1. **手算、scipy 和 statsmodels 必須一致。** 三者都給出 **5.57（3.41–9.10）**。
2. **讀說明文件的預設值。** scipy 的 `odds_ratio` 必須指定 `kind="sample"`。它的預設是*條件式* OR（5.54），那是另一種估計式，不是錯誤。
3. **方向：** OR 大於 1，且涉水的病例比對照多。兩者吻合。
:::

## 風險比還是勝算比？

**風險比（risk ratio, RR）**是把暴露組的*風險*，除以未暴露組的風險，$\frac{a/(a+b)}{c/(c+d)}$。這需要所有的風險族群，那是世代研究才給得出來的。在病例對照研究裡，要取多少對照是*我們自己選的*，所以我們這張表裡的「風險」取決於我們的設計。筆記本示範了這一點：每個病例配兩位對照時，那個假的「RR」是 3.21；每個病例配一位對照時，變成 2.37，而 OR 幾乎不動（5.57 對 5.18）。**世代研究 → RR。病例對照研究 → OR。** 當疾病罕見時，OR 會接近 RR。

:::{div}
:class: ph-game ph-game-two-by-two
列是暴露，欄是結果。世代研究比較風險（RR）；病例對照研究比較暴露的勝算（OR），絕不用 RR。
:::

## 雨鞋與 doxycycline

雨鞋只對曾經在水裡的人才重要，所以這個問題**只問涉水者**（174 人）。其中，穿雨鞋的 **OR 是 0.35**（95% CI 0.16–0.80）。服用 **doxycycline 預防性投藥**（在疏散中心及發給清理志工），**OR 是 0.43**（0.21–0.86）。兩者在*這場虛構的疫情裡*都是保護因子。在房子附近看到老鼠，在這裡沒有造成差異（OR 1.03，0.67–1.60）。

關於 doxycycline 預防性投藥在現實中的使用（誰該用、何時用、用多少劑量），請遵循衛生部（DOH）目前的指引和你的醫師，而不是這本書。

## 干擾因子：涉水還是清理？

Doc Mon 注意到了：*「清理志工涉水涉得比較多，不是嗎？而且清理工作本身也有風險。」* **干擾因子（confounder）**是和暴露有關、**而且**本身就是該疾病的危險因子的第三個因素，所以它的效應會混進粗 OR 裡。在對照組中，做清理工作的人有 69.1% 涉過水，其他人則是 21.5%，而清理工作本身的 OR 是 3.20。

所以 Maya 做**分層分析**：她分別為有做和沒做清理工作的人，各算一次涉水的 OR。然後用 **Mantel–Haenszel**（MH）勝算比把兩者合併，這是各層 OR 的加權平均：

| 分層 | a | b | c | d | OR |
|---|---:|---:|---:|---:|---:|
| 沒做清理工作 | 32 | 37 | 21 | 135 | 5.56 |
| 有做清理工作 | 58 | 47 | 9 | 21 | 2.88 |
| **粗 OR（全部人）** | 90 | 84 | 30 | 156 | **5.57** |
| **Mantel–Haenszel** | | | | | **4.28**（2.53–7.27） |

**改變了什麼？為什麼？** 一旦把清理工作固定住，涉水的 OR 從 5.57 降到 4.28。粗數字有一部分屬於清理工作，因為清理工作者涉水涉得更多。涉水與鉤端螺旋體病仍然有強烈的關聯。兩個分層的 OR 看起來不同，但以這些數字來說，檢定無法把它們和機遇區分開來（p ≈ 0.24），所以用一個 MH 彙整值是合理的。男性在粗表裡看起來有風險（OR 2.82）也是同樣的原因：男性涉水涉得更多。筆記本讓你可以自己驗證。

:::{div}
:class: ph-game ph-game-quiz
**小測驗：找出感染源**

1. 你算出來的 OR 是 0.18，但 75% 的病例和 35% 的對照有暴露。發生了什麼事？
   - ✓ 表格有一個軸被翻轉了 — 讀列和欄的標籤；真正的 OR 是 1 ÷ 0.18。
   - 這個暴露是保護因子 — 病例暴露的比例比對照高，就不是。
2. 在病例對照研究裡，你應該報告……
   - 風險比 — 對照的數目是調查者選的，所以風險並不真實。
   - ✓ 勝算比與它的 95% 信賴區間。
3. 依清理工作分層之後，涉水的 OR 從 5.57 降到 4.28。這表示……
   - 涉水不重要 — 它仍有強烈關聯，OR 大約是 4。
   - ✓ 清理工作干擾了粗 OR — 它的一部分效應混了進來。
